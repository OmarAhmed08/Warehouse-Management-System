# Warehouse Management System 📦

A lightweight, fully interactive web application for managing inventory, tracking stock levels, and streamlining warehouse operations. Built using modern vanilla JavaScript, HTML5, and CSS3.

---

## 🚀 Features
- **Full CRUD Operations:** Add, edit, update, and delete products seamlessly.
- **Product Categorization:** Organize inventory by categories for structured stock tracking.
- **Search & Live Filtering:** Instantly search products by name or category.
- **Data Persistence:** Utilizes browser `localStorage` to keep data intact across page refreshes.
- **Responsive Design:** Clean, modern interface optimized for desktop and mobile devices.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid, CSS Variables)
- **Scripting:** JavaScript (ES6+)
- **Storage:** Browser Web Storage API (`localStorage`)
